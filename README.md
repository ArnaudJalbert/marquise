# Marquise

`Marquise` is an open-source platform for aggregating and exploring movie showtimes.

Focused on Montreal, it gathers screening data from multiple theaters, normalizes it, and exposes it through an API and an evolving application interface.

The goal is to build a complete, user-friendly product on top of reliable, structured cinema data.
