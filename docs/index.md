# Marquise

Montreal cinema showtimes — aggregated, normalized, and queryable.

Marquise fetches showtime data from theater chains and independent cinemas across Montreal, normalizes it into PostgreSQL, and exposes it through a CLI and a read-only REST API.

Live API: [marquise-api.fly.dev/docs](https://marquise-api.fly.dev/docs)
