# Marquise

**Marquise** is an open-source platform for aggregating and exploring movie showtimes
in Montreal. It gathers screening data from multiple theaters, normalizes it, and
exposes it through a REST API.

## Technology

| Layer       | Technology                                          |
|-------------|-----------------------------------------------------|
| Language    | Python 3.13                                         |
| API         | FastAPI (coming soon)                                |
| Database    | PostgreSQL via Supabase                             |
| Testing     | pytest, pytest-asyncio                              |
| Code Style  | Ruff (format + lint)                                |
