# Marquise Atlas

**Marquise Atlas** is the private organizational knowledge base for Marquise.

It is the source of truth for strategy, product and operational context, agent charters, working processes, project briefs, decisions, reviews, and research.

## Boundaries

- **This vault:** company knowledge and operating context.
- **`ArnaudJalbert/marquise`:** code, issues, pull requests, CI, releases, deployments, and implementation history.

Do not duplicate GitHub records here. Link to the relevant GitHub URL instead.

## Navigation

Start at [[00-home/Company Home]]. Read [[50-processes/Documentation and Delivery Workflow]] for the execution loop.

## Note conventions

Use frontmatter where it improves findability. Prefer explicit status, owner, review date, and links to related notes. Keep active notes current; archive superseded material rather than silently overwriting history.
